# 무드보드 포스트 스튜디오

뷰티·패션 게시물용 카드 5장과 캡션·해시태그를 만드는 작은 웹앱입니다.
ChatGPT Sites에서 받은 앱을 GitHub Pages에서 실행할 수 있는 HTML/CSS/JavaScript로 바꿨습니다.

## 사용 방법

1. `index.html`을 더블클릭해 엽니다.
2. 주제·분야·말투를 선택하고 **5장 기본 초안 만들기**를 누릅니다.
3. 각 카드의 제목과 본문, 캡션과 해시태그를 직접 수정합니다.
4. **배경 바꾸기**로 색상이나 립 이미지를 선택하고 **이미지 저장**으로 1080×1350 PNG를 받습니다.
5. 캡션과 해시태그는 복사 버튼으로 복사합니다. 자동 복사가 안 되면 선택된 글을 `Ctrl+C`로 복사합니다.

입력 내용과 초안은 브라우저의 `localStorage`에 자동 저장됩니다. 서버로 보내지 않습니다.
같은 브라우저·사이트에서 다시 열면 불러오며, 다른 기기와 공유되지는 않습니다.
브라우저 데이터를 삭제하면 초안도 사라집니다. 파일을 직접 연 경우 브라우저 설정에 따라 저장이 제한될 수 있습니다.
**이 브라우저에 저장된 내용 지우기** 버튼으로 삭제할 수 있습니다.

## 원래 앱과 달라진 점

GitHub Pages에는 서버가 없으므로 Sites 전용 AI 생성·최신 자료 조사·무료 사진 검색 기능은 사용할 수 없습니다.
이 버전은 검색 결과처럼 보이는 내용을 만들지 않고, 미리 준비한 문구 틀과 색상 배경을 사용합니다.
립 주제에는 로즈·코랄·로즈베이지 립스틱과 발색을 보여주는 AI 예시 이미지를 사용합니다.
실제 브랜드 제품의 사진이 아니며, 특정 제품의 실제 발색과 다를 수 있습니다. 이 안내는 저장하는 PNG에도 표시됩니다.
문구는 직접 작성하고 사실을 확인한 뒤 게시하세요. 인스타그램에 자동 게시하는 기능은 없습니다.

## GitHub Pages에 올리기

1. GitHub 저장소에 아래 **6개 파일과 `assets` 폴더**를 올립니다. 저장소 맨 위에 `index.html`이 있어야 합니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. 파일을 올린 브랜치(보통 `main`)와 **/(root)**를 선택하고 **Save**를 누릅니다.
4. 배포가 끝나면 Pages 화면에 표시된 주소를 엽니다.

빌드나 패키지 설치는 필요하지 않습니다. 파일 경로는 `./`로 시작하므로 저장소 이름이 붙는 주소에서도 작동합니다.
공개 저장소에 개인 이미지나 연락처가 들어 있는 파일을 추가하지 않도록 확인하세요.

## 파일 구성

- `index.html`: 화면의 구조와 시작 파일
- `style.css`: 색상·글꼴·모바일 화면 디자인
- `app.js`: 초안 만들기·수정·브라우저 저장·PNG 다운로드
- `assets`: 립 예시 이미지와 브라우저에서 불러오는 이미지 데이터
- `.nojekyll`: GitHub Pages가 파일을 그대로 제공하도록 하는 빈 파일
- `.gitignore`: 임시 파일이나 비밀 설정을 Git에 올리지 않도록 하는 목록

외부 서버·API 키·외부 글꼴 없이 실행됩니다.

`.original-source` 폴더는 수정 전 원본 백업입니다. Sites 전용 서버 코드와 설정도 이곳에 보관했습니다.
웹앱 실행에는 필요 없으며 GitHub에 올리지 마세요. Git을 사용하면 `.gitignore`가 이 폴더를 제외합니다.
GitHub 화면에서 직접 파일을 올릴 때는 `.gitignore`가 자동 적용되지 않으므로 위 6개 파일과 `assets` 폴더만 선택하세요.
